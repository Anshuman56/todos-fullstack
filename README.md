# Todos Fullstack

You can create, update, delete, and retrieve todos using this full stack app.

[Live Demo](https://todos-fullstack-eight.vercel.app/)

![Screenshot](icons.svg "Screenshot")

## Features

- Create and store todos.
- View todos in the frontend.
- Toggle a todo's completed status.
- Delete any todo.

## Tech Stack

Built with Express, JavaScript, Node.js, Mongoose and React.

## What I Learned

I learned how to connect a React frontend to an Express backend and perform CRUD operations using a REST API.

## How to Run It Locally

```bash
git clone https://github.com/Anshuman56/todos-fullstack
cd todos-fullstack
npm install
node server.js
```
